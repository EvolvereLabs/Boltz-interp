# Decodability — figure data provenance

Maps every decodability figure the manuscript includes to its data file(s), the script that produced
that data, and the metric shown. Figures are generated by `_build_paper_a_figures.py` (main) and
`_build_paper_a_supplementary.py` (supplementary); both write `.pdf` + `.png` to
`decodability/figures/`.

Per-script reference: [`DECODABILITY_SCRIPT_MAP.md`](DECODABILITY_SCRIPT_MAP.md).

## Common pipeline

- **Model:** Boltz-1. Two stacks — **Pairformer trunk** (recycle 1; layers 0–47, SAEs on even layers
  + 47) and **diffusion module** (sampling steps 0, 1, 10, 50, 100, 199; layers 0–22).
- **SAEs:** TopK k=256, 2048 latents, trained on **demeaned** activations, ℓ2 = 3e-3, 3 seeds,
  500k steps. Trained on 84,074 proteins (21.9M residues), evaluated on the SwissProt-A5 set.
- **Evaluation set:** the 486 proteins in `inputs/common_activation_proteins.txt` — the intersection
  of proteins with activations at every (layer, rec), so `n_proteins` is identical across layers and
  modules.
- **Concept labels:** `swissprot_annotation_pipeline.py` (UniProt → per-residue multi-hot);
  DSSP secondary structure from AlphaFold (`secondary`) or from Boltz's own CIF (`boltz_secondary`);
  amino-acid identity (`build_amino_acid_concepts.py`).

Only recycle 1 is committed. The rec0 tree backed a robustness panel the manuscript does not
include; dropping it leaves the informativeness filter (and therefore every figure) unchanged.

## Metric glossary

| metric | definition | train/test |
|---|---|---|
| **probe-raw** | ℓ2 logistic probe on **raw activations**, grouped K-fold by protein, scored out-of-fold | held-out |
| **probe-SAE** | same probe on **SAE latents** (alive only) | held-out |
| **SAE-1feat** | F1 of the single best SAE latent (argmax over 2048 latents × 5 activation-percentile thresholds) | in-sample |
| **neuron-1feat** | same recipe on raw neurons | in-sample |
| **signal** | F1 − permutation null (null = best-of-features F1 under circularly-shifted labels) | — |
| **F1** | domain-level: per-residue precision × per-domain recall (a domain is recalled if ≥1 positive prediction overlaps it) | — |

## Data files and generating scripts

| data file | produced by | key fields |
|---|---|---|
| `data/sae_explore/layer_sweep_rec1/benchmark/layer{L}/{swissprot,secondary}_agg.json` | `run_parallel_benchmark.py` → `aggregate_seed_benchmark.py` | per-concept `sae_f1_mean`, `sae_null_mean`, `neuron_f1`, `probe_raw_f1`, `probe_sae_f1_mean` |
| `data/sae_explore/diffusion_analysis/rec{R}/benchmark/layer{L}/*_agg.json` | same, `--layer_type diffusion` | same schema |
| `{secondary,boltz_secondary}_seed{1,2,3}_benchmark.json` (per layer dir) | `run_layer_benchmark.py` (per seed) | per-concept `probe_raw_f1`, `sae_f1_mean` |
| `data/sae_explore/amino_acid_sanity/results.jsonl` | `amino_acid_sanity_check.py` | `layer_type, layer, amino_acid, probe_f1, sae_f1, neuron_f1` |
| `data/sae_explore/amino_acid_sanity/cross_seed_results_diffusion.jsonl` | `amino_acid_cross_seed.py --layer_type diffusion` | `layer, rec, amino_acid, sae_f1_mean, decoder_cos_mean` |

| `data/homology/probe_homology_*` | `check_probe_homology.py` | pairwise identity matrix + >30% pairs (Limitations) |

## Reproduce

```bash
cd decodability
python _build_paper_a_figures.py
python _build_paper_a_supplementary.py
python -m jupyter nbconvert --to notebook --execute --inplace paper_a_figures.ipynb
python -m jupyter nbconvert --to notebook --execute --inplace paper_a_supplementary.ipynb
python make_tables.py
```

Use the project env — the S7 cell imports `aggregate_seed_benchmark`, which pulls in `tap` and
`torch`. Edit the generators, not the `.ipynb`; direct notebook edits are wiped on regen.
